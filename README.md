# Auto_tza_parser
## 1. Введение
Программа "Автопарсер ТЗА" предназначена для автоматизации верификации технологических схем на автоматизацию, конкретнее - для сравнения перечня датчиков и электроприводных арматур из файлов pdf c табличными данными. Программа позволяет значительно сократить время ручной перенос данных и повышает точность верификации при обработке больших объемов информации.
## 2. Требование к системе
Перед использованием программы убедитесь, что ваш компьютер соответствует следующим требованиям:
- Операционная система: Windows
- Имеется разархивированная папка с файлами ТЗА в формате PDF. В папке содержатся **только** необходимые для обработки файлы.
- Имеется папка, куда можно складывать итоговые журналы замечаний.
## 3. Установка программы
1. Скачайте архив программы или получите его от разработчика
2. Разархивируйте папку. Убедитесь, что в папке dist есть файлы tza_Schemes и best_new_new.pt.
3. Запустите приложение auto_tza.exe
3. Программа запускается достаточно медленно, проявите терпение)
4. Если при запуске программы в консоли возникают ошибки, возможно, необходимо доустановить на компьютер библиотеки. За помощью обратитесь к разработчику программы.
## 4. Руководство пользователя
Откройте файл “tza_Schemes” в папке dist. Появится пустая консоль, а затем, через несколько секунд, появится окно программы. 

### Шаг 1: Загрузка PDF-файлов 
Нажмите на первую кнопку «Выбрать папку». Появится проводник, чтобы выбрать папку, в которой хранятся исходные файлы ТЗА в формате PDF. После выбора папки, в окне программы появится путь к папке, которую Вы указали 
### Шаг 2: Выбор директории для сохранения файлов
Нажмите на вторую кнопку «Выбрать папку». Появится проводник, чтобы выбрать папку, в которую вы хотите сохранить файлы с перечнем элементов схем. После выбора папки, в окне программы появится путь к папке, которую Вы указали 
### Шаг 3: Обработка файлов
Нажмите на кнопку «Обработать PDF файлы». Если вы не указали папку с исходными данными или папку для сохранения, появится окно ошибки.
Если все папки были указаны правильно, программа начнет выполняться. Это может занять несколько минут. Дождитесь, когда появится окно успешного подтверждения завершения работы.

### Шаг 4: Завершение работы
Если больше нет файлов, которые необходимо обработать, закройте сообщение нажатием на «ОК» и окно программы нажатием на крестик в правом верхнем углу.

### Шаг 5: Проверка результата
Откройте папку, которую указывали для сохранения списков, и убедитесь, что файлы действительно появились в папке. Файлы будут называться в соответствии с кодами исходных данных ТЗА.
